# BPP account work claims

Start review atomically reserves work for the server-authenticated appraiser. A matched CAD account shares one reservation across business, inactive-account, and mailing alerts within the same district. Unmatched alerts use their source table and item ID. Claims survive closing a browser and remain until release, completion, dismissal, or an explicit district-admin release. This is a reservation, not an online-presence indicator. Historical IN_REVIEW rows are not assumed to be actively worked until claimed.

The queue and detail screen display the owner and start time. Ownership is polled every 30 seconds while the queue is visible and checked immediately on opening a detail. Other appraisers can read the account details but cannot start, complete, dismiss, or change its CAD match. Every mutating API operation atomically checks/acquires ownership, so stale tabs cannot bypass the reservation. Owners release explicitly; admins can clear stuck claims after coordinating with the appraiser. Completion/dismissal releases only after the review write succeeds. Release events are recorded in activity analytics.

Apply `supabase/migrations/20261028_bpp_work_claims.sql` before deploying. The table has RLS and is inaccessible to anon/authenticated clients; only the existing service role can access it. District, actor, account keys, and admin authority come from server-side context and loaded queue records. The primary key arbitrates simultaneous starts across app instances; a per-district transaction lock also protects unmatched-to-matched item aliases. CAD confirmation reserves the proposed account before saving its decision; old reservations remain until the review is released/completed to preserve protection through a match change.

Claims cover BPP intelligence and mailing review workflows. Rendition document editing and Commercial are separate workflows. There is no automatic timeout: closing a page is not proof that someone stopped working in the CAD system. A district admin can release a claim when an appraiser is unavailable. An explicit admin release can interrupt ownership; coordinate with the appraiser before releasing it.
